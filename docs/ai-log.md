# AI 활용 기록

작성일 2026-11-06. 이 기록은 실제 대화의 요청과 수행 결과를 정리한다. 사용자가 직접 편집하거나 시연했다는 사실을 만들어 넣지 않는다.

## 사용자 요청

1. VS Code에서 작업 중인 프로젝트와 함께 작업 가능한지 질문했다.
2. 로컬 프로젝트 경로를 제공했다.
3. 과거 상세 검토·개발 계획서 전문을 첨부하고 ‘이걸 기반으로 프로젝트 제작해줘’라고 요청했다.
4. ‘어떤 방향성으로 어떤걸 했는지 전부 세세하게 기록해줘’라고 추가 요청했다.

## AI가 한 작업

계획서와 실제 파일의 차이를 확인하고 사용자에게 설명했다. FANPLAY 선수 커리어 방향, 데이터 계약과 저장 트랜잭션, 보상·티켓 연결, 로컬 커뮤니티·프로필을 구현했다. 시나리오·선택지·아이템명·디자인·코드를 작성하고 재현 가능한 Node 검사 스크립트를 만들었다. 원본 백업과 지정 폴더 반영 절차를 준비했다.

## 초안에서 수정한 부분

초기 최고 선택 능력치 [5,4,5]에서 레전드 도달 경로가 1개뿐인 결과를 확인했다. [6,5,6]으로 변경 후 157개 경로가 됐다. CSS 반복 열 선언의 괄호 오타를 수정했다. 실제 검수 가능 범위를 넘는 주장을 하지 않도록 README·검사 기록에 실제 브라우저 미검증을 명시했다.

## 사람의 참여와 수정

사용자는 목표 문서·폴더·기록 요구를 제공했다. 이 작업 중 사람의 직접 코드 수정, 실제 브라우저 시연, 밸런스 승인, 사용자 테스트 결과는 전달되지 않았다. 따라서 사람의 수정이나 최종 검수 완료로 기재하지 않는다. 작업 전 기존 파일은 사람이 보유하던 프로젝트이며 그 작성 과정은 이번 대화만으로 알 수 없다.

## 실행 검증

로직 11검사 통과, 템플릿 렌더 12검사 통과, 두 유형 합계 13,122경로 검사. 저장 실패는 localStorage.setItem 예외 주입으로 재현했다. 실제 브라우저 미리보기는 네트워크/소켓 제한으로 열리지 않아 화면·사진·모바일 검증을 완료하지 못했다. 실제 명령과 결과는 test-checklist와 development-log에 있다.

## AI 사용 범위 설명

이 앱의 ‘생성형 AI 활용’은 제작 과정의 기획·문구·코드·테스트·문서 작성이다. 앱 실행 중 LLM 호출, API 키, 서버 생성, 자동 사실 조회는 없다. 앱 내부 콘텐츠는 창작이며 실제 경기 정보나 선수 기록으로 표시하지 않는다.
