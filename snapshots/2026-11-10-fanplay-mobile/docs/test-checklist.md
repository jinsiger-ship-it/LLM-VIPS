## 재현 명령

프로젝트 폴더에서 `node tests/integration.cjs`, `node tests/screens.cjs`. 첫 검사는 TOTAL 11 PASS, 둘째는 TOTAL 12 SCREEN RENDERS PASS를 출력한다. DOM 대체 환경은 브라우저 CSS·사진·포커스·실제 input 이벤트를 검증하지 않는다.

## 사람이 실행할 통합 점검

- [ ] index를 실제 브라우저에서 열고 콘솔 오류 확인
- [ ] 날짜·팀·점수 입력, 다음 단계·이전 단계에서 입력 유지
- [ ] 클래식·전광판·포토 각각 저장과 새로고침
- [ ] 사진 없이, 정상 JPG/PNG/WebP, 12MB 초과, 손상 이미지 테스트
- [ ] 사진 처리 중 버튼 잠금 및 사진 제거 확인
- [ ] 게임 4시즌 진행 후 새로고침, 5시즌으로 이어짐 확인
- [ ] 세 결말과 보상, 잠금 해제, 티켓 적용 후 새로고침
- [ ] 대표 티켓과 칭호 선택 후 새로고침, 대표 삭제 후 빈 화면 확인
- [ ] 게시·좋아요·댓글·원본 삭제 후 사본 확인
- [ ] 작은 휴대전화와 PC에서 모든 메뉴·버튼·사진 검수
- [ ] 키보드 탭 이동·명시적 라벨·포커스·알림 확인
- [ ] 다른 브라우저에서 데이터가 보이지 않음을 안내와 대조

검수자는 날짜/브라우저/뷰포트/재현 순서/실제 결과/수정 파일을 이 문서 뒤에 추가한다. 미실행 항목을 통과로 바꾸지 않는다.
