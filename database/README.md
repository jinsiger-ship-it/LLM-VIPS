# FANPLAY 데이터베이스

`node server.cjs`를 처음 실행하면 이 폴더에 `fanplay.sqlite`가 생성됩니다. SQLite 보조 파일도 같은 위치에 생성될 수 있습니다. 계정, 비밀번호 검증값, 세션, 계정별 기록을 저장합니다. 실제 데이터 파일은 Git과 웹 서버의 정적 파일 제공 범위에서 제외됩니다.

개발 외 환경에서 데이터를 지속 보관하려면 `FANPLAY_DATABASE`에 영속 저장 디스크의 파일 경로를 지정하세요. 운영 서버를 종료한 뒤 데이터베이스를 백업하고, 백업 파일에는 운영자만 접근할 수 있도록 관리하세요.
