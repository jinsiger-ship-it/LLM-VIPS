# FANPLAY

## ▶️ FANPLAY 실행하기

**[⚾ FANPLAY 모바일 웹앱 바로 실행](https://jinsiger-ship-it.github.io/LLM-VIPS/)**

새 탭에서 열려면 Windows에서는 `Ctrl`, Mac에서는 `⌘`를 누른 채 클릭하세요. 모바일에서는 링크를 길게 눌러 **새 탭에서 열기**를 선택하세요.

**[🎮 게임 화면 바로 실행](https://jinsiger-ship-it.github.io/LLM-VIPS/#game)**

야구 관람 티켓을 만들고 수집하며 선수 커리어 게임을 즐기는 모바일 웹앱입니다. 로그인하면 계정에 기록을 보관합니다. 비회원 기록은 같은 탭에서만 이용할 수 있고, 새로고침하거나 탭을 닫으면 사라집니다.

이전 버전에서 이 브라우저에 보관한 기록은 로그인 후 계정 관리에서 선택해 가져올 수 있습니다. 보관본은 각 시점의 저장 방식을 사용합니다.

---

## 현재 버전: v0.11.1

- 티켓 만들기에서 **경기 날짜와 구단 또는 구장**을 고르면 Supabase에 등록된 2026 KBO 종료 경기의 팀·구장·최종 점수가 입력돼요. 여러 경기가 나오면 원하는 경기를 고를 수 있어요.

- 로그인하면 백업 파일 가져오기와 티켓 임시저장을 이용할 수 있어요. 비회원은 이번 방문 중에 티켓을 만들고 KBO 결과 파일을 누적할 수 있어요.
- 공개 커뮤니티와 선수 랭킹의 새 기능은 [Supabase 적용 안내](docs/reliability-release.md)의 SQL을 적용한 뒤 활성화돼요.

- 로그인 후 헤더의 **계정 및 기록 관리**에서 저장 도구와 로그아웃을 이용할 수 있어요. 버튼에는 선택한 응원팀 테마가 적용돼요.
- 마이에서 로그인 화면으로 이동할 수 있어요. 비회원 수집함에는 이번 방문 중 만든 티켓을 보여줘요.
- [공용 커뮤니티](https://jinsiger-ship-it.github.io/LLM-VIPS/#community)에서 직관·커리어 티켓을 공유하고 최신순, 좋아요·댓글 순위를 볼 수 있습니다.
- 다른 기기에서 같은 아이디로 기록을 불러올 수 있으며, 공개 글과 댓글의 삭제 권한은 작성한 브라우저에 연결됩니다. [Supabase 구성 및 이전 데이터 적용 안내](docs/demo-community-setup.md)

- 모바일 UI 개선을 적용했습니다. 홈의 주·보조 행동, 후보 비교, 경기 선택지, 장식 적용 상태, 저장 상태를 정리했습니다.
- 선수 생성에서 240점 압축형 후보와 기존 300점 직접 배분을 모두 사용할 수 있습니다.
- [desktop-tutorial](https://github.com/jinsiger-ship-it/desktop-tutorial)의 온라인 시연 기록을 같은 아이디로 이어갈 수 있습니다.

**[회원가입](https://jinsiger-ship-it.github.io/LLM-VIPS/#register) · [로그인](https://jinsiger-ship-it.github.io/LLM-VIPS/#login)**

- 회원가입에서 시연용 아이디와 응원팀을 선택합니다. 로그인에서는 가입한 아이디로 온라인 기록을 불러옵니다.
- 아이디는 영문·숫자·밑줄 3~24자이며 대문자는 소문자로 저장합니다.
- 비밀번호 없는 공유 시연입니다. 아이디를 아는 누구나 기록을 열고 수정할 수 있으므로 개인정보·개인 사진은 넣지 마세요.
- 이전에 기기에 남은 기록이나 이번 방문의 비회원 기록은 로그인 후 **계정 및 기록 관리**에서 선택해 가져올 수 있습니다. 다른 기기의 변경과 충돌하면 현재 기록을 내려받은 뒤 온라인 기록을 다시 불러옵니다.
- 로그아웃하면 이번 탭의 비회원 상태로 돌아갑니다.
- 공개 DB 연결·두 브라우저 이어하기·저장 충돌·게임 기록 동기화를 검증했습니다. [설정과 저장 방식](docs/cloud-demo-setup.md)

- 선수 선택: 포지션·좌우 투타 + 240점 후보 3명, 요청한 1안의 압축 카드 UI.
- 선택 사건 26개, 이어지는 약속·라이벌·훈련, 은퇴 호칭 추천.
- 장식 20종을 티켓 꾸미기에 통합. 기존 선수와 티켓은 보존.
- 로컬 Node 서버의 비밀번호 계정 기능은 유지합니다. 공개 페이지에서는 별도의 시연용 공유 아이디를 사용합니다.
