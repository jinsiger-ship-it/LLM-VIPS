FANPLAY
FANPLAY 모바일 바로가기

야구 관람 티켓을 만들고 수집하며 선수 커리어 게임을 즐기는 모바일 웹앱입니다. GitHub Pages에서 만든 기록은 브라우저에 저장됩니다.

같은 브라우저의 이전 FANPLAY 기록은 첫 실행에 읽어옵니다. 이후 메인과 보관본의 기록은 별도로 저장됩니다.

로컬 계정 실행
Node.js 24 이상으로 저장소 폴더에서 node server.cjs를 실행합니다. 로컬 마이페이지에서 회원가입과 로그인을 사용할 수 있습니다. 비회원 기록은 브라우저에, 로그인 후 저장한 티켓과 게임 기록은 로컬 SQLite DB에 보관합니다.

node tests/integration.cjs, node tests/screens.cjs, node tests/accounts.cjs로 검사할 수 있습니다. 실제 SQLite 파일은 Git과 Pages 배포 대상에서 제외됩니다. [DB 안내](database/README.md)

3. 연결된 KBO JSON 데이터에서 해당 조건에 맞는 경기를 찾습니다.
4. 찾은 경기 정보를 화면에 표시합니다.
확인 필요: KBO에서 직접 제공하는 JSON/API를 사용할지, KBO 홈페이지의 정보를 별도로 수집해 JSON으로 저장할지 결정되지 않았습니다. 경기 정보의 확정 출력 필드, 데이터 갱신 주기, 경기 미존재·취소·동일 조건 복수 경기 처리 방식도 아직 정해지지 않았습니다.
